# RelGeo Language Spec

Status dokumen: `Spec Hub`

Tanggal: `2026-07-22`

Folder ini sekarang berfungsi sebagai hub untuk source language-spec multi-bahasa.

Struktur awal yang aktif:

1. `id/` untuk source aktif yang saat ini dipakai sebagai rumah normatif utama
2. `en/` disiapkan sebagai rumah publik untuk versi Inggris

Untuk saat ini:

1. kontrak bahasa aktif yang dipakai implementasi dan docs-site berada di `id/`
2. route publik docs-site tetap hidup di `/docs/language-spec/`, tetapi loader internal membaca source dari pohon bahasa aktif di repo ini

Jika Anda mencari spec aktif sekarang, mulai dari:

1. [id/README.md](./id/README.md)
2. [id/editorial-guide.md](./id/editorial-guide.md)

Catatan:

1. dokumen ini adalah pintu struktur bilingual, bukan pengganti isi spec aktif
2. keputusan tentang status normatif `id` vs `en` dijaga terpisah sebagai keputusan editorial dan public-surface
